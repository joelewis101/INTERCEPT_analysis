# INTERCEPT analysis

Analysis scripts outputs for the UKRI funded
[INTERCEPT](https://gtr.ukri.org/projects?ref=UKRI1001) project.

## Repo structure

Scripts are in `scripts/` folder. Local copy has a `data` folder that is not
pushed to the repo - raw data (e.g. culture data) should go in `data/raw/` and
cleaning scripts will load, process and save in `data/processed/`.

## Data sources

Culture data is stored in a series of spreadsheets, one for each sample type.
This is currently shared via google drive

Metadata is in the REDCap database.
